# Integração com o RTK Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** O Cockpit detecta, ativa/desativa (com confirmação) e vigia o RTK no Claude Code, e mostra no Analytics quanto ele economizou.

**Architecture:** Um pacote novo `internal/rtk` encapsula tudo que toca o binário e o `settings.json` (busca, estado, check de saúde, prévia, ativar/desativar com cópia, gain com cache, intervalos de ativação no KV). O monitor de integrações recebe o check `rtk` junto da saúde do Claude. A API expõe estado, prévia, ação e economia; a store calcula o antes/depois com os dados do NAC-31. A UI ganha um cartão na Configuração e um bloco no Analytics.

**Tech Stack:** Go (os/exec, net/http, SQLite), React + TypeScript + TanStack Query + Vitest.

**Spec:** docs/superpowers/specs/2026-11-18-rtk-design.md

## Global Constraints

- O Cockpit nunca baixa nem instala o binário do RTK; só roda o `rtk` já instalado, e só ativa/desativa por ação explícita confirmada na tela.
- Ativar = `rtk init -g --hook-only --auto-patch`; desativar = `rtk init -g --uninstall`; prévia = o mesmo comando com `--dry-run`.
- Busca do binário: PATH do usuário (`launch.UserPATH`), depois `~/.cargo/bin/rtk`, depois `~/.local/bin/rtk`.
- Timeouts: 5 s para `--version`, `gain` e `--dry-run`; 20 s para `init`.
- Hook ativo = em `~/.claude/settings.json`, `hooks.PreToolUse` com matcher que casa `Bash` e algum comando contendo `rtk hook claude`.
- Antes de `init` (ativar ou desativar): copiar o `settings.json` para `settings.json.bak-rtk-<AAAAMMDD-HHMMSS>` no mesmo diretório, mantendo só as 3 cópias mais recentes; não restaurar sozinho.
- `rtk gain --daily --format json` em cache de 60 s; falha → "indisponível", sem derrubar a rota.
- Intervalos de ativação no KV `rtk_activations` = `[{"on": RFC3339, "off": RFC3339 | ""}]`.
- Antes/depois: só `tool = 'Bash'`; antes = saídas com `at` < primeira ativação; depois = saídas de sessões com `started_at` dentro de algum intervalo [on, off) (off vazio = agora); mínimo 5 chamadas de cada lado; ordenado por chamadas (antes + depois) desc; até 15 linhas; variação = (média depois − média antes) / média antes × 100.
- Totais do gain no período: dias com `date` (AAAA-MM-DD local) em [from, to); % = Σsaved / Σinput × 100.
- config_log: tipos novos `rtk_on` e `rtk_off`.
- Textos de tela em português, curtos.

## Review Focus

- Daemon sob systemd com PATH mínimo: o `rtk` em `~/.cargo/bin` precisa ser achado (Task 1, `TestFind_Fallbacks`).
- `settings.json` ausente ou inválido: estado "inativo" com detalhe, check com código `no_settings`/`unreadable`, nenhuma ação escreve sem o arquivo (Task 1).
- Usuário que ativou o RTK à mão antes do Cockpit: o check vira OK, entra na linha de base e um intervalo é aberto na primeira vez que é visto (Task 1 `TestCheck_OpensIntervalForManualActivation`).
- Desativar pelo Cockpit não gera alerta de integração quebrada (Task 3, `TestRTKDeactivate_NoAlert` com o monitor real).
- `rtk gain` lento/quebrado: a rota de economia responde rápido com `available:false` e o antes/depois mesmo assim (Task 3).

  ```go
  type KV interface {
      GetKV(key string, v any) (bool, error)
      PutKV(key string, v any) error

  type Status struct {

      Version     string     `json:"version"`      // "1.2.0" (sem o prefixo "rtk ")

  type GainDay struct {
      Date         string `json:"date"`
      Commands     int64  `json:"commands"`
      InputTokens  int64  `json:"input_tokens"`
      OutputTokens int64  `json:"output_tokens"`
      SavedTokens  int64  `json:"saved_tokens"`
  }
  type Tool struct {

      Run func(ctx context.Context, bin string, args ...string) ([]byte, error)
  }
  func (t *Tool) Find() string
  func (t *Tool) Status(withVersion bool) Status
  func (t *Tool) Check() adapter.Check // Key "rtk", Label "RTK ativo no Claude Code"
  func (t *Tool) Preview(action string) (string, error)       // action: "activate" | "deactivate"
  func (t *Tool) Apply(action string) (out string, backup string, err error)
  func (t *Tool) Gain() ([]GainDay, error)                    // cache 60 s
  func (t *Tool) Activations() ([]Interval, error)
  ```
